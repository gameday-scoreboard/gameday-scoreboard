The Game Day card puts a QR code for [gameday-scoreboard.com](https://gameday-scoreboard.com) on the panel between games, with a few words like **WANT THIS SCOREBOARD AT HOME?** beside it. It's for a scoreboard other people see, so anyone who likes it can scan the code and find out where to get one.

## Turn it on

The card is off to start. Turn on **Game Day card** under **Between games** on the [device page](/using/device-page/), or in the app. Turn it off the same way.

## What it shows

Every 20 minutes between games the card takes the screen for 10 seconds, then the board comes back. Each turn uses the next of four wordings, so it doesn't say the same thing every time.

- **On a 128x64 display** the code is on the left and the words are beside it.
- **On one 64x64 panel** the words show first, then the code takes the screen for the rest of the turn.

## When it steps aside

The card works like the [message card](/using/messages/#a-message-card): it never covers a live game, a celebration or the panel's own trouble messages, like **No internet**. It doesn't come up while another between-games card is showing, and it waits 10 seconds after the message card, the news card or a picture goes down. A message card on **Whenever no game is on** keeps it off.
