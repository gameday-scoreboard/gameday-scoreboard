DIY installer

Game Day Scoreboard for a controller you built yourself on the MoonHub75 pinout.

Install

Which panels does yours drive? Click the picture that matches, so the scoreboard starts with the right layout. You can change it later on the device page.

Then plug the controller into this computer over USB and click Install.

This browser cannot talk to the controller over USB. Try a desktop browser. Open this page over HTTPS to install.

Needs an ESP32-S3 HUB75 controller on the MoonHub75 pinout, with 16MB flash and octal PSRAM. Have a Game Day Scoreboard controller? Use the main installer.

Other boards, panel sizes and wiring a bare ESP32-S3 are on Runs on your own panel.

Installing erases whatever firmware was on the controller. Your WiFi details and team choice are asked for afterwards.

After installing

Joining WiFi and picking your team work the same as on the Game Day Scoreboard controller. Follow steps 2 and 3 on the main installer page. Updates arrive over WiFi from then on, built for your pinout.

Source, issues and the YAML for building it yourself: gameday-scoreboard/gameday-scoreboard. Built on hub75-studio and ESPHome.
