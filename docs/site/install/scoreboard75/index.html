scoreboard75 installer

Game Day Scoreboard for a test controller on the scoreboard75 pinout.

Install

Plug the controller into this computer over USB and click Install. One firmware covers a single 64x64 panel and two panels side by side; you pick which on the device page afterwards.

This browser cannot talk to the controller over USB. Try a desktop browser. Open this page over HTTPS to install.

Only for controllers built on the scoreboard75 pin map. Not sure which you have? Use the main installer.

Installing replaces whatever firmware was on the controller. WiFi comes next, in the same window.

After installing

Joining WiFi and picking your team work the same as on any controller. Follow steps 2 and 3 on the main installer page. Updates arrive over WiFi from then on, built for this pinout.

Source, issues and the YAML for building it yourself: gameday-scoreboard/gameday-scoreboard.
