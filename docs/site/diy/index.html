Runs on your own panel

The Game Day Scoreboard firmware is open source under the MIT license. If you have an ESP32-S3 HUB75 controller and a panel, you can run it for free.

Boards

MoonHub75

The MoonHub75 has a prebuilt firmware. Install it from your browser with the installer and it takes updates over Wi-Fi like any other panel.

An ESP32-S3 board wired to the MoonHub75 pinout

The same prebuilt firmware runs on a bare ESP32-S3 board if you wire it to the same pins. It needs:

  • An ESP32-S3 with 16 MB of flash and 8 MB of octal PSRAM, like a dev board with an N16R8 module
  • A button from GPIO0 to ground. The BOOT button on most dev boards is already wired that way. It shows the panel's address, resets Wi-Fi and does a factory reset.
  • The panel wired to these pins (ESPHome's names; the MoonHub75 README calls the upper half R0, G0 and B0):
R1G1B1R2G2B2ABCDELATOECLK
156713916484721388418

Many panels read the ESP32's 3.3 V signals fine. If yours flickers or shows the wrong colors, put 5 V level shifters (74AHCT245 or similar) between the board and the panel.

Other boards

Any other ESP32-S3 HUB75 board with at least 16 MB of flash and octal PSRAM, the Waveshare ESP32-S3 RGB Matrix among them, needs its own build. There's no prebuilt firmware for these and we haven't tested them. Copy firmware/controllers/moonhub75.yaml with your board's pins, copy firmware/gameday.yaml to include it, and build that with ESPHome.

Give your copy its own variant name. A build that keeps moonhub75 installs the MoonHub75 release over itself when an update comes out, with the wrong pins. With its own name, the panel updates when you rebuild it.

Panels

One 64x64 panel
One 128x64 panel or two 64x64 side by side

One firmware drives both. You pick the layout in the installer and can change it on the panel's page later. It's made for the common indoor HUB75 panels with an E pin (1/32 scan). Other sizes, like 64x32, aren't supported.

Power the panels from a 5 V supply rated for them; the panel's listing gives the current it draws at full brightness.

Install

Plug the board into a computer over USB, open the installer in Chrome or Edge, pick one panel or two, and click Install.

Open the installer

Joining Wi-Fi, picking a team and the Game Day app work the same as on a Game Day Scoreboard. Setup covers the rest.

Building from YAML instead? The README has the steps.

What's different from a Game Day Scoreboard

  • You supply the case, stand and power supply.
  • Email support is for Game Day Scoreboards we sold. For a panel you built, open an issue on GitHub. Bug reports from DIY builds are welcome.
  • The firmware is the same, with every league and setting. The prebuilt firmware for the MoonHub75 pinout gets every release.
