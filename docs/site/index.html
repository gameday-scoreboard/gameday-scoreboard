1. Install

Plug the controller into this computer over USB and click Install. One firmware covers a single 64x64 panel and two panels side by side; you pick which on the device page afterwards.

This browser cannot talk to the controller over USB. Try a desktop browser. Open this page over HTTPS to install.

For the Game Day Scoreboard controller. Built your own on a MoonHub75 board? Use the DIY installer instead. Using another board? See Runs on your own panel.

Installing erases whatever firmware was on the controller. Your WiFi details and team choice are asked for afterwards.

2. Join WiFi

When the install finishes the same dialog offers to connect the device to WiFi. Enter your network name and password. If you skip it, the panel starts a hotspot named Game Day plus six letters and numbers, like Game Day 2f6a70, and shows the name on screen; join it and a setup page opens.

3. Pick your team

The panel itself tells you where to go once it's online: open the gameday-xxxxxx.local name it shows on your phone, or the address shown under it if your phone doesn't resolve .local names.

  1. Tap Change team and pick from the logos, a tab per league, or use the On now tab to jump into a game that's already playing.
  2. Two panels side by side? In the Setup card, click the two-panel picture. The matrix restarts using both.
  3. The timezone follows the phone or computer you opened the page on, so kickoff times read right without setting anything.
  4. Optional: the ticker parts, opponent celebrations, up to 16 favorite teams (the first four on a WizMote remote), or Live games, which follows a random game in progress in the leagues you pick.

The panel shows the next game with the line, TV network and start time, switches to the live board at the start, celebrates scores, and lingers on the final. The page mirrors it, lists the next three games in football and soccer, and updates the firmware when a new version is out, by itself if you turn that on. The panel gets its scores from ESPN by itself. No Home Assistant needed, though the device does show up there if you want it.
